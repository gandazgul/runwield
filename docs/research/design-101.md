# Design 101

NN/g is https://www.nngroup.com/

## Visual hierarchy

NN/g defines it as organizing page elements so the eye sees them in the intended order of importance. It can be created
with contrast, scale, grouping, and placement.

The simple test:

│ If I look for 3 seconds, what do I notice first, second, and third?

## Grouping and spacing

Core idea:

│ Things that are close together look related. Things that are farther apart look separate.

This is the principle of proximity. NN/g states that items close together are usually understood as one group, and
spacing can be used to unite or separate elements.

### Why this matters

Bad spacing can make users ask:

- “Does this label belong to this field or the next one?”
- “Which price goes with which plan?”
- “Is this error message about this input?”
- “Are these buttons part of the same choice?”

Good spacing makes relationships clear before the user reads carefully.

Simple rule

Use spacing like punctuation:

- Small space = these things belong together.
- Large space = this is a new group.
- Same spacing repeated = these groups are equal.

## Alignment and layout

Core idea:

│ Alignment gives the page an invisible structure. │ Alignment should make scanning easier, not only make things look
balanced.

When things line up, the design feels organized and is easier to scan. When every item starts in a different place, the
user must do extra work to understand what belongs where.

### Simple rule

Pick a few strong lines and reuse them:

- Left edges line up.
- Related text starts on the same vertical line.
- Buttons line up with the content they act on.
- Cards in a row share the same top edge and width.

Do not align everything to everything. Use alignment to show structure.
